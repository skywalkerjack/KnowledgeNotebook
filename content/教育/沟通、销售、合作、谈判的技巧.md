# 沟通、销售、合作、谈判的技巧

本文档整理自当前文件夹中的 6 个中英文对照提示词、3 个 `.skill` 技能包，以及安装说明。核心思想可以概括为一句话：

> 在任何重要沟通、销售、合作、谈判、内容发布或组织协作之前，先站到对方的位置，弄清楚对方真正优化的收益、害怕失去的东西、承受的限制，以及你的行为在对方眼里释放了什么信号。

---

## 一、核心方法论

这些提示词和 skills 共用同一套底层框架：不要从“我想要什么”出发，而要从“对方真正想保住什么、得到什么、避免什么”出发。

### 1. 真实收益 Payoff

真实收益不是对方口头说想要的东西，而是对方在现实中真正会被驱动的东西。

常见问题：

- 如果对方答应我，他真正得到什么？
- 如果对方拒绝我，他在保护什么？
- 对方当前最在乎的目标、KPI、关系、风险或安全感是什么？
- 我的请求是在帮他实现目标，还是在消耗他的资源？

### 2. 表面诉求 vs 真实动机

对方说出来的理由，往往只是表层阻力。真正的决策点藏在“他说的”和“他行为暴露的”之间。

常见表层说法：

- 太贵了
- 预算不够
- 时机不对
- 我们再看看
- 没有人手
- 不现实
- 我需要考虑一下

需要继续追问：

- 这句话背后真正的恐惧是什么？
- 对方怕承担什么后果？
- 对方怕失去什么控制权、资源、关系或身份？
- 我之前的表达是否触发了他的防御？

### 3. 隐性限制

对方不是拥有无限选择的人。每个对方都被自己的预算、人力、时间、上级、客户承诺、声誉压力、关系网络和历史经验限制着。

需要识别：

- 预算限制
- 团队产能
- 决策权限
- 截止时间
- 平台或流程依赖
- 既有承诺
- 声誉和面子压力
- 与其他人的关系牵连

### 4. 信号分析

你的报价、提案、内容、请求或开场方式，都会向对方释放信号。很多失败不是因为方案本身不行，而是因为你无意中让对方读出了风险、单边索取、低诚意或高不确定性。

需要分析：

- 我的开场让对方觉得这是机会，还是负担？
- 我的报价暴露了什么底线？
- 我的内容前三秒让受众看到价值，还是看到自嗨？
- 我的合作提案看起来是双赢，还是功劳归我、活归对方？

### 5. 低成本高价值让步

最好的推进方式不是一味让利，而是找到对自己成本很低、对对方价值很高的筹码。

例子：

- 分阶段执行
- 先做小范围试点
- 主动承担一部分风险
- 给对方可见的署名、荣誉或业绩归属
- 帮对方解决他正被考核的问题
- 降低对方需要向上解释的成本

## 二、6 个商业情报提示词

### 1. MAP YOUR CLIENT'S MIND：绘制客户心智地图

适用场景：销售对话、客户跟进、报价前准备、处理客户异议。

目标：在销售前读懂客户真实想法、恐惧、诉求和即将做出的决定，让报价、推介和跟进都围绕客户现实展开。

启动问题：

- 我的产品或服务是什么？
- 目标客户是谁？
- 最近一次销售对话或客户互动发生了什么？

分析流程：

1. 绘制客户真实收益地图：同意会得到什么，拒绝会失去什么，真正优化什么。
2. 找出口头诉求与行为诉求之间的鸿沟。
3. 识别客户不会说出口的背景恐惧。
4. 预测客户即将提出的异议。
5. 给出能回应底层恐惧的销售话术。
6. 调整报价、推介和定位。

输出格式：

```text
客户收益地图
→ 表面与真实诉求对比
→ 潜在恐惧地图
→ 异议预测
→ 具体的推介与定位调整方案
```

检验标准：如果客户读到这份分析，会觉得自己在销售对话中从未如此被理解。

---

### 2. PREDICT YOUR COMPETITOR：预判竞争对手

适用场景：竞争分析、市场动作判断、竞品反应预测、制定先发策略。

目标：代入竞争对手的业务现实，判断他们正在优化什么、受什么限制、下一步最可能怎么做。

启动问题：

- 主要竞争对手是谁？
- 我目前的市场定位是什么？
- 我们双方最近一次市场动作是什么？

分析流程：

1. 绘制竞争对手真实收益地图。
2. 找出竞争对手的隐藏限制：预算、团队、客户承诺、平台依赖、声誉压力。
3. 从竞争对手视角分析我最近释放的信号。
4. 预测对手接下来最可能的三个动作，并按概率排序。
5. 给出本周可执行的先发制人行动。

输出格式：

```text
竞争对手收益地图
→ 隐藏限制条件
→ 我的信号分析
→ 三个预测行动（按概率排序）
→ 先发制人的应对策略
```

检验标准：如果竞争对手读到这份分析，会觉得自己业务中最关键的地方被看穿。

---

### 3. DECODE YOUR PARTNERSHIP：解码合作伙伴

适用场景：建立合作、修复合作、设计分成方案、联合项目谈判。

目标：在提出合作方案前，先弄清楚合作方真正想获得什么、害怕失去什么、如何看待当前提案。

启动问题：

- 我想建立或修复什么合作？
- 对方的商业模式是什么？
- 当前关系状态如何？

分析流程：

1. 绘制合作伙伴真实收益地图。
2. 识别对方进入或继续合作时害怕失去什么。
3. 从对方立场分析当前提案是否有风险、不平衡或缺乏吸引力。
4. 重构合作结构，让双方收益都清晰可见。
5. 设计先谈对方收益、再谈自己诉求的对话脚本。

输出格式：

```text
合作伙伴收益地图
→ 隐藏恐惧分析
→ 对方视角下的当前提案
→ 合作关系重构方案
→ 合作谈判对话脚本
```

检验标准：如果合作伙伴读到这份分析，会觉得合作是为他们设计的，而不是单纯被推销给他们的。

---

### 4. READ YOUR AUDIENCE：读懂你的受众

适用场景：内容创作、短视频、图文、社交媒体、课程或社群内容优化。

目标：从受众打开内容的那一刻出发，弄清楚什么让他们停留、划走、收藏或分享。

启动问题：

- 我的内容赛道是什么？
- 目标受众是谁？
- 最近三条内容是什么？数据表现如何？

分析流程：

1. 绘制受众内容收益地图：他们打开 App 时想解决什么问题。
2. 找出停留或划走的具体触发点。
3. 分开分析收藏触发点和分享触发点。
4. 从受众视角复盘最近三条内容。
5. 提供未来内容可复用的公式。

输出格式：

```text
受众收益地图
→ 流失/停留触发点
→ 收藏触发点
→ 分享触发点
→ 最近三篇内容剖析
→ 可复制的内容公式
```

检验标准：如果目标受众读到分析，会在每一行里认出自己。

---

### 5. WIN BEFORE YOU NEGOTIATE：赢在谈判前

适用场景：价格谈判、供应商谈判、合作条款、客户压价、资源交换。

目标：在谈判前绘制对手的真实收益、压力点、恐惧和底线信号，提前设计开场、让步和收尾。

启动问题：

- 我正在准备什么谈判？
- 对方是谁？
- 我想从谈判中得到什么？
- 我目前知道对方处境的哪些信息？

分析流程：

1. 区分对方表态立场和真实收益。
2. 识别对方压力点：期限、预算周期、关系利害、声誉、替代方案。
3. 分析我的开局立场释放了什么信号。
4. 找出低成本高价值让步。
5. 设计完整谈判策略：开场、中局、收尾。

输出格式：

```text
对手收益地图
→ 压力点剖析
→ 开局信号分析
→ 高价值低成本的让步筹码
→ 完整的次序化谈判策略
```

检验标准：如果谈判对手提前看到这份分析，会觉得我拥有了不公平的优势。

---

### 6. BUILD YOUR INTELLIGENCE SYSTEM：构建战略情报系统

适用场景：个人创业者、业务负责人、长期决策系统搭建。

目标：把“站进别人视角”变成每次重大商业动作前的固定流程，而不是临时灵感。

启动问题：

- 理想客户是谁？
- 主要竞争对手是谁？
- 核心合作伙伴是谁？
- 目标受众是谁？
- 最近最重要的谈判是什么？

系统组件：

1. 五维参与者地图：客户、竞争对手、合作伙伴、受众、谈判对象。
2. 收益映射协议：任何重大动作前，用 5 个问题映射相关方收益。
3. 10 分钟视角审计：确保真的代入对方，而不是以为自己懂。
4. 假设挑战：用 3 个问题区分“我以为”和“行为证据”。
5. 每周 15 分钟战略情报复盘：持续校准五类参与者变化。

输出格式：

```text
五维参与者地图
→ 收益映射协议
→ 视角审计机制
→ 假设挑战测试
→ 每周战略情报复盘
→ 完整操作系统
```

检验标准：运行 90 天后，不再单纯基于自己对他人诉求的想当然假设做重大决策。

## 三、3 个可安装 Skill

这 3 个 `.skill` 文件是已封装的技能包，内部都包含一个 `SKILL.md`。它们可以安装到 Claude Code 或类似支持 skill 的 AI Agent 中。

### 1. cross-dept-collab：跨部门协作情报官

适用场景：

- 跨部门沟通
- 项目需要其他团队支持
- 其他部门不配合
- 协调资源
- 推动协作项目

开始前 4 个问题：

1. 你要找哪个部门？这次协作或谈判的核心诉求是什么？
2. 对方部门目前最大的压力、KPI 或关注点是什么？
3. 你们之间是否有历史摩擦或合作前例？结果如何？
4. 如果协作成功，对方部门能得到什么？

工作流程：

1. 绘制对方部门真实收益地图。
2. 找出对方部门运作的隐性限制。
3. 分析你的请求在对方眼里是什么样的。
4. 设计让对方感觉赢了的合作结构。
5. 预测对方可能抛出的推脱理由。
6. 交付完整跨部门沟通策略。

输出格式：

```text
【对方部门收益地图】
→ 配合的真实收益 / 拒绝的真实动机 / 对方的核心压力

【隐性限制清单】
→ 具体列出 2-3 条对方你看不到的约束

【你的请求在对方眼里的样子】
→ 目前释放的信号 / 对方的解读 / 需要修正的地方

【让对方感觉赢了的设计】
→ 可见收益 / 荣誉分配 / 互惠让步

【推脱预测 + 应对】
→ 推脱 / 真实原因 / 应对方式

【完整跨部门沟通策略】
→ 接触方式 / 开场框架 / 合作结构 / 推进节奏
```

---

### 2. daily-persuasion：日常说服情报官

适用场景：

- 想说服家人
- 跟朋友闹矛盾
- 想跟伴侣谈重要的事
- 对方不理解我
- 不知道怎么开口
- 说了也没用

开始前 4 个问题：

1. 你想跟谁谈？这次想谈什么事？
2. 对方最近状态如何？有没有压力或顾虑？
3. 你们上一次谈这件事或类似事情是什么结果？
4. 你希望谈完后对方发生什么变化？

工作流程：

1. 站进对方的世界。
2. 找出“说的”和“真正在意的”之间的距离。
3. 找出对方不会直接说出口的顾虑。
4. 找到让对方感觉被看见的切入点。
5. 预测对方可能的反应。
6. 交付完整对话策略。

输出格式：

```text
【对方的世界】
→ 目前最在意的 / 答应的真实收益 / 拒绝的真实动机

【说的 vs 真正在意的】
→ 表面说法 / 背后情绪或顾虑 / 你过去沟通方式的问题

【隐性顾虑清单】
→ 具体列出 1-2 条

【让对方感觉被看见的切入点】
→ 可以先说的话 / 真正对对方有利的角度

【反应预测 + 回应方式】
→ 反应 / 背后需求 / 回应方式

【完整对话策略】
→ 时机选择 / 开场 / 中间应对 / 结尾
```

重要提醒：这个 skill 不是为了赢得争论或操控对方，而是为了真正理解对方，找到双方都能被尊重的沟通方式。

### 3. managing-up：向上管理情报官

适用场景：

- 跟领导谈加薪
- 推方案
- 申请资源
- 被老板否掉
- 不知道怎么跟上级开口

开始前 4 个问题：

1. 你想跟领导谈什么？
2. 领导目前最大的压力或关注点是什么？
3. 上一次沟通这件事或类似事情的结果如何？
4. 你希望领导做出什么具体决定或动作？

工作流程：

1. 绘制领导真实收益地图。
2. 找出“说的”和“真正在意的”之间的鸿沟。
3. 绘制领导不会说出口的恐惧。
4. 预测领导会抛出的反对意见。
5. 找出低成本高价值让步点。
6. 交付完整沟通策略。

输出格式：

```text
【领导收益地图】
→ 答应的真实收益 / 拒绝的真实动机 / 核心优化目标

【说的 vs 真正在意的】
→ 表面理由 / 背后真实顾虑

【隐性恐惧清单】
→ 具体列出 2-3 条

【反对意见预测 + 话术】
→ 反对意见 / 真实恐惧 / 应对话术

【低成本高价值让步点】
→ 你可以主动让出什么 / 对领导的价值是什么

【完整沟通策略】
→ 开场 / 中局应对 / 收尾
```

检验标准：如果领导读到这份分析，会觉得自己的真实顾虑被准确看见。

## 六、Skill 安装与使用

以 Claude Code 为例，安装方式是将 `.skill` 文件解压到全局 skills 目录：

```bash
unzip xxx.skill -d ~/.claude/skills/
```

其中 `xxx.skill` 替换为实际文件名，例如：

```bash
unzip managing-up.skill -d ~/.claude/skills/
```

安装完成后，通常可以通过 `/skill-name` 的方式调用。如果没有显示，重启 Claude Code 或其他支持 skill 的 AI Agent 后再试。

## 七、最重要的实践原则

1. 不要急着说服，先弄清楚对方在保护什么。
2. 不要只听对方说了什么，要看对方行为暴露了什么。
3. 不要把异议当阻力，要把异议当恐惧的外壳。
4. 不要设计只有自己赢的方案，要让对方的收益清晰可见。
5. 不要泛泛共情，要具体指出对方的压力、限制和风险。
6. 不要给长期空话，要给下一次对话前就能执行的动作。
7. 不要基于假设行动，要基于对方真实收益行动。

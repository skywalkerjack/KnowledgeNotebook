# 一瓶水带你搞懂赚钱的真相（水的3种卖法）

## 一句话总结
同一瓶水，价格从2块到1000块，取决于你把它放在什么场景、卖给谁、用什么方式卖。赚钱的本质不是卖产品，而是卖认知。

## 核心知识点

### 1. 定价的第一层秘密：稀缺性决定价格
- **价格不由成本决定，而由稀缺性决定**
- 同一瓶水：
  - 超市：2元
  - 便利店：3元
  - 火车站：5元
  - 机场：10元
  - 五星级酒店：30元
  - 高端会所：60元
  - 贴上依云标签：翻5倍
  - 换成巴黎水：再翻3倍
  - 装进爱马仕瓶子：卖到1000元，还有人抢着买
- **稀缺性由场景决定，而非产品本身**

### 2. 定价的第二层秘密：心理需求溢价
- 当物质需求被满足后，人们愿意为心理需求付出更高溢价
- 买农夫山泉的人，买的不是水，是"我是一个对生活品质有要求的人"这个身份标签
- **你在卖什么决定了你能卖多少**

### 3. 三种商业逻辑：卖产品、卖服务、卖解决方案

| 模式 | 本质 | 天花板 | 例 |
|------|------|--------|-----|
| 卖产品 | 赚差价 | 体力上限 | 摆摊卖水，一瓶瓶卖 |
| 卖服务 | 赚时间 | 服务人数上限 | 桶装水配送，开水店 |
| 卖解决方案 | 赚认知 | 问题大小决定价值 | 净水器系统 |

**本质区别：在食物链上的位置不同**
- 卖产品：货没了价值就没了
- 卖服务：时间有限，收入有天花板
- 卖解决方案：问题越大，越不可替代，定价权越强

### 4. 感知价值才是真正的价值
- 茅台成本不超过100块，卖3000元
- 钻石本是一块石头，被戴比尔斯绑定爱情
- **人们愿意付多少钱和东西真正值多少钱几乎没关系**
- 有关的是：信息不对称、情绪共情、社会认同、锚定效应、损失厌恶

### 5. 穷人与富人的思维差距
- **穷人思维**：我的东西这么好，为什么卖不出价格（在做产品）
- **富人思维**：我要怎么让别人觉得我的东西只这个价格（在做认知）
- 前者在证明自己，后者在塑造感知

## 易错点
1. **以为成本+利润=定价**：定价从来不是数学题，而是心理学题
2. **一直卷成本、卷效率、卷性价比**：真正赚钱的人不在这个维度竞争
3. **用卖产品的方式出售自己**：按时间计费、按件计费，体力天花板就是收入天花板

- 产品价值包装

## 行动清单

### 第一个突破口：重新定义你的稀缺性
- 在有一万个人能干的岗位上 = 超市2块钱的水
- 在只有100个人能干的岗位上 = 机场10块钱的水
- 在只有10个人能干的岗位上 = 限量款
- **让自己变得稀缺不是学一个冷门技能，而是把几个常见技能叠加在一起**
  - 会写代码 + 会做营销 + 能讲课 = 稀缺

### 第二个突破口：从卖时间升级到卖解决方案
- 不要只完成任务，要理解任务背后的目的
- 不要只提交结果，要能解释为什么这个结果是对的
- 不要只当手脚，要开始当脑子

### 第三个突破口：学会经营你的感知价值
- 写文章、做分享、建立个人品牌
- 让别人知道你能解决什么问题
- **你的能力是内瓶水，你的表达是那个标签，你的圈子是那个货架，你的口碑是那个品牌故事**

## 核心公式
```
你能赚到的钱 = 你能帮别人解决多大的问题 × 别人能感知到这个解决方案的程度
```

## 关键问题（每次想赚钱时问自己）
1. 我解决的问题够不够大？
2. 别人知不知道我能解决这个 problem？

# Codex 保姆级攻略，海量实战教程

## 一句话总结
Codex 是 AI 编程助手，支持项目级沙箱、并行任务、Git 工作流、自动化、Skills 插件系统，可本地或云端运行。

---

## 核心知识点

### 1. 安装与准备
- 需先安装 **Gate、Note DS、VS Code**
- 支持 Windows 和 Mac（Mac 缺少 Computer Use 功能）
- 登录 Codex GPT 账户（免费账户额度较低）
- 首次使用选择工作场景（编程/日常），可后续在设置中修改
- 启动后完成沙盒初始化

### 2. 项目管理与并行任务
- 三栏布局：左侧任务列表 → 中间对话窗口 → 右侧多功能区
- 支持同时运行多个项目，每个项目独立文件夹
- 快捷键：`Ctrl+Shift+N`（Windows）/ `Cmd+Shift+N`（Mac）
- 任务状态：转圈（运行中）→ 蓝色小点（已完成）→ 绿色标签（等待批准）

### 3. 沙盒安全机制（核心）
- Codex 把当前项目文件夹作为**沙盒**进行管理
- 两项硬性限制：**不能修改沙盒外文件** + **禁止联网**
- 通过操作系统底层机制（Windows: Citrix Box）实现，非模型自觉遵守
- 如需沙盒外操作或联网：发起 **Sculpture（提权申请）**

### 4. 权限等级
| 等级 | 说明 |
|------|------|
| 默认模式 | 直接修改沙盒内所有文件，无需逐个审批 |
| 自动审查（推荐） | 低风险操作自动放行，高风险才触发人工审批 |
| 完全访问 | 可执行一切操作，有醒目的风险提示 |

### 5. 上下文管理
- 显示当前上下文使用量，快过期时 Codex 自动压缩对话历史
- 可手动触发压缩（输入框选择压缩选项）
- **经验：清空 > 压缩**，完成任务后开新对话有助于 AI 集中注意力

### 6. 模型与套餐
- 可选不同思考强度的模型（如 GPT-5.5）
- 速度模式：标准 / 快速（提升 50% 推理速度，但消耗 2 倍套餐用量）
- 套餐余量：5 小时额度 + 周额度，任一到达上限则无法使用

### 7. AI 生图功能
- 内置 DALL-E 生图模型
- 可让 Codex 生成图片、修改网页配图
- 用 **STIR 功能（引导干预）**可纠正 AI 执行方向，按快捷键 `Ctrl+Shift+Enter`

### 8. 计划模式
- 开启后 Codex 不立即干活，先输出完整工作计划，确认后再执行
- 适合所有复杂任务，确保 AI 精准理解意图

### 9. 代码管理与 Git 工作流
- 需先将项目初始化为 Git 工程
- 可直接用 VS Code 等 IDE 打开项目
- 支持对话式 Git 操作（提交到 GitHub 等）
- **回滚方法**：
  1. 对话历史回滚：用 Focus（分叉）功能选择"派生到本地"
  2. 代码回滚：在 Codex 内点击 Source 按钮查看所有 Git 提交 → 右键复制提交哈希 → 让 Codex 把代码回退到该状态

### 10. Git Walkthrough（分支并行开发）
- 基于主干预创建多个工作树（永久工作区），每个在独立文件夹
- 各分支并行开发互不干扰，开发完后合并回主干预
- 右键可移除不再需要的分支

### 11. 云端运行
- 需先推送代码到 GitHub 同步
- 在 Codex 外部（网页版）运行项目
- 手机可打开 Codex 网页版，在外无电脑时可通过云端完成工作

### 12. 记忆系统
- **项目级记忆**：在项目根目录创建 `AI Rules.md` 文件，每次对话自动带入上下文
- **全局记忆**：设置 → 个性化 → 自定义指令，对所有项目生效
- 建议加上禁止批量删除的全局提示词（保护整个地盘）
- 实验性功能：**琴记忆** 可从聊天中生成新记忆带入新对话

### 13. 插件与自动化
- 插件市场提供多种第三方服务（GitHub 插件、邮件插件等）
- **自动化**：可定时执行任务（如每周五发邮件汇报）
- Codex 每次执行完会自动把经验写成 `Memory.md`
- 可配合流染器自动化 + Computer Use 做出更多玩法

### 14. Skills（技能系统）
- Skills 是给 AI 的整体专业技能包/标准化工作流
- **三种安装方式**：官方 Skills、第三方 Skills、自己创建 Skills
- 自己创建：通过 Codex 内置的 Skills Creator 技能来创建
- Skills 适合将视频转图文、定制化工作流等场景标准化

### 15. MCP（模型上下文协议）
- 通过 MCP 可让 Codex 连接外部数据库（如 Supabase）
- 在设置 → MCP 服务器中添加
- 开启后可用自然语言操作数据库，完成增删改查

### 16. Computer Use（电脑自动化）
- 目前**仅 Mac 可用**
- 用虚拟光标在后台自动操作电脑
- 可打开软件、发消息、浏览网页等
- 开启防止系统休眠选项可确保自动化定时任务正常执行

---

## 易错点
- Codex **默认直接修改文件**，不一个个问，需注意开启自动审查
- 批量删除文件会被禁止，只能一个个删，AI 严格遵守此约定
- STIR 引导时新指令默认进入指令队列排队，需点引导按钮或按快捷键 `Ctrl+Shift+Enter`
- Computer Use 功能仅 Mac 可用，Windows 用户无法体验
- 对话回滚（Focus）只回滚对话历史，不回滚代码，需配合 Git 操作一起回滚

## 适用场景
- 需要并行处理多个项目代码的开发者
- 想用 AI 自动化执行定时任务（发邮件、汇总报告）
- 希望用自然语言操作 GitHub、数据库（Supabase）等外部服务
- 需要 AI 编程+自动化+生图一体化的工作流
- 出门在外无电脑时，用手机通过云端完成编程任务
